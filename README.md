# 🧴 SkinWise — AI-Powered Skincare Recommendation Assistant

**SkinWise** is an intelligent skincare recommendation system built using **Retrieval-Augmented Generation (RAG)**.  
It suggests the best skincare products based on user queries such as skin type, concern, or budget — using web-scraped data, semantic search, and LLM-based reasoning.

---

## 🧠 Overview

### ✨ What it Does
- Scrapes skincare product data (name, ingredients, price, skin type, etc.)
- Stores and indexes data in MongoDB and Qdrant
- Uses embeddings to perform semantic product similarity search
- Generates human-like recommendations using LLMs
- Offers an interactive Gradio interface for easy querying
